# 文風與用詞校對指南

酒館卡的閱讀體驗很大程度取決於文字本身的語感，不是只有設定夠不夠豐富。這份指南預設目標語言是**繁體中文、台灣用語與敘事習慣**，因為多數使用本技能的創作者是為台灣讀者/使用者寫卡。如果使用者明確要其他語言或地區用語（例如簡體中文、香港用語、英文），全部依使用者指示調整，不要硬套下面的規則。

## Step 1：先跟使用者確認語感目標

不用假設，直接問或從使用者提供的範例文字判斷：

- 敘事節奏偏電影感的分鏡描寫，還是輕小說式的輕快對話？
- 用詞偏文雅內斂，還是偏口語俏皮？
- 有沒有特定要規避的詞彙庫（例如使用者明確討厭的網路用語）？

如果使用者貼了一段自己喜歡的範例文字（像參考卡片那樣），直接分析它的句型長短分佈、動詞使用習慣、換行節奏，當作這張卡的文風錨點。

## Step 2：繁體中文台灣用語對照檢查

寫 `system_prompt`、`mes_example`、`first_mes` 時，比對以下常見的兩岸用詞差異，統一使用台灣慣用說法（除非使用者要求相反）：

| 避免（中國大陸用語） | 建議（台灣用語） |
|---|---|
| 視頻 | 影片 |
| 質量（指品質時） | 品質 |
| 立馬 | 馬上 |
| 早上好／中午好／下午好／晚上好 | 早安／午安／晚安（或依情境自然帶入問候，不用死板套招呼語） |
| 我給你買 / 我給你做飯 | 我買給你 / 我煮給你吃（台灣習慣把「動詞＋給」放在受詞後面，而非中國大陸常見的「給＋動詞」倒裝） |
| 給你擦一下（服務性動作) | 幫你擦一下（服務性動作用「幫」而非「給」） |
| 视觉/信息/软件等大陸慣用詞 | 視覺／資訊／軟體 |

如果使用者的角色設定本身要求更嚴格（像參考卡片示範的「絕對禁止祖宗、混不吝、丫頭、嬌氣、作精、勾引、尤物、惹火等大陸網文用語」），可以把這種**明確禁用詞庫**直接寫進 `system_prompt` 的語言風貌規範段落，讓模型在生成時自我審查，而不是只在校對階段才抓。

## Step 3：敘事技法檢查點

跟使用者確認要不要在 `system_prompt` 裡明確加入以下敘事原則（這些原則能顯著提升角色扮演文字的品質，但不是每張卡都需要全部用上，依卡片調性取捨）：

1. **Show, don't tell（具象化情緒，反後設）**：禁止直接宣告心理狀態或照抄設定標籤（例如不要寫「他展現了完美的社交面具」），改成用具體的微表情、肢體動作、對環境物件的干涉來呈現情緒。
2. **分鏡式換行**：把每個段落當一個獨立鏡頭，敘事焦點從宏觀環境切到微觀肢體接觸、或從對話切到內心活動時，用實體換行（空行）切換，避免超過三個以上的動作/情緒轉折擠在同一段。
3. **句型節奏**：短句（約 15 字內）用於動作與衝擊，中長句（搭配連詞、逗號）用於鋪陳心境與氛圍；避免「名為...的...」「像...一樣的...」這類公式化的虛假比喻。
4. **名詞去標籤化**：提到角色的特定物品或口頭禪時，自然融入語句,不要用引號刻意標記成「設定關鍵字」的樣子。
5. **禁止後設描述與劇情引導**：不要在旁白裡出現「系統偵測到」「進入遊戲模式」這類暴露底層邏輯的句子；如果卡片設計上不想要選項式互動，也可以明講「不提供選項、不詢問玩家意願，直接演繹」。

## Step 4：對話範例（`mes_example`）品質檢查

寫 2-3 組對話範例時，確認：

- 每組範例是否示範了不同的情境/情緒強度，而不是重複同一種語氣？
- 角色的口頭禪、稱呼習慣、句尾語氣詞是否前後一致？
- 如果有心理狀態的階段設計（Stage 2 checklist 的「進展脈絡」），至少有一組範例要體現「表象與內心的落差」，讓模型抓到這個角色的核心張力寫法。

## Step 5：最終校對

組裝完整張卡之後，快速掃過 `description`、`personality`、`scenario`、`first_mes`、`mes_example`、`system_prompt`：

- [ ] 沒有殘留簡體字或大陸慣用詞（除非使用者要求）
- [ ] 語氣在不同欄位之間一致（`personality` 描述的性格跟 `first_mes` 實際演出的語氣對得上）
- [ ] 沒有意外洩漏「深層設定/隱藏屬性」的關鍵詞在使用者還沒解鎖的欄位裡
- [ ] 標點與斷句符合台灣習慣（例如使用「……」而非「...」，引號用「」而非純英文引號，依卡片整體風格決定要不要嚴格套用）
