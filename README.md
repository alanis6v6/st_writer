# st_writer

這個 repo 裝兩種東西，刻意分開放，不要混在一起：

```
.claude/skills/sillytavern-card-generator/   ← 技能本體
cards/<卡片代號>/                             ← 作品：一張卡一個資料夾
```

## `.claude/skills/sillytavern-card-generator/` — 技能

這是**通用的、可重複使用**的工具，跟任何一張特定的卡無關。它是一套工作流程：用檢核表跟使用者對話、依酒館觸發機制設計世界書、用 regex 做視覺美化、評估要不要上 MVU 變量、校對繁中用詞、最後組裝成 JSON 並跑試玩實測。

裡面的檔案：

| 路徑 | 內容 |
|---|---|
| `SKILL.md` | 主流程與八個階段 |
| `references/` | 各階段的細部指南（世界書、變量、regex、文風、卡片格式、試玩） |
| `assets/` | 可直接複製填寫的卡片骨架與 regex 範本 |
| `scripts/playtest_engine.py` | 試玩模擬用的 CLI：精確計算世界書觸發、套用 regex、套用變量更新 |

**這裡面不應該出現任何特定角色的姓名、設定或劇情。** 需要舉例時用中性的佔位內容。

## `cards/` — 作品

每張角色卡一個資料夾，裡面是那張卡專屬的內容：設定草稿、世界書內容、開局文本、regex 腳本、最終的 `.json`，以及那張卡自己的待辦事項。

目前的卡片：

- `cards/gender-is-not-the-limit/` — 《性別不是限制，性吸引力才是》

**這裡面的東西不會回頭影響技能。** 技能是怎麼做卡的方法，作品是做出來的成果。

## 交付物

酒館只吃單一個 `.json` 檔。`cards/<代號>/` 裡的 `.md` 都是工作草稿，方便逐段討論修改；最終會組裝成一個可直接匯入的 `chara_card_v3` JSON（含世界書與 regex 腳本），放在該卡片資料夾下。
